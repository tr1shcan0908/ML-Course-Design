# 第二轮：先解释大误差，再做有限实验

制定日期：2026-10-22。下列三项设置在读取第二轮实验结果前确定。

第一轮选中热图与精修等权平均，80 张折外图的坐标 RMSE 为 13.8676 像素。最大误差样本 0049 占总平方误差 33.56%；前五个样本占 67.65%。精修验证 ROI 覆盖率为 100%，但单独使用精修反而退步。因此不能仅凭“增加局部细节”断言会更准，也不能删除难样本来改善指标。

## 本轮实验

| 编号 | 变化 | 固定内容 | 目的与边界 |
|---|---|---|---|
| R2-A | 精修 ROI 从原图 512 扩大至 768，仍缩放为 256 输入 | 初始化、折、学习率、100 epoch 上限、早停规则、损失 | 检查扩大视野的实用收益；同时改变物理像素尺度、Gaussian 宽度和按 ROI 定义的扰动，并非完全隔离上下文的因果实验 |
| R2-B | 二维 Gaussian CE 改为 X/Y 边缘概率的四尺度 CE | ResNet18-U-Net、512 输入、Gaussian 目标、DSNT、坐标 MSE、120 epoch 上限、增强与折 | 单独比较监督目标；不新增大模型，不宣称复现 MSCE 或 SimCC |
| R2-C | 已训练的 fine_512 固定使用中心、上下左右五个裁剪，偏移为 ROI 的 1/8，原图坐标等权平均 | 第一轮权重、ROI 大小、全局 DSNT，无翻转 | 检查预测对裁剪位置的敏感性，计算量约为单次精修的五倍；验证和测试均只以粗预测为锚点 |

R2-A 与 R2-B 完成全部五折，沿用原训练预算和早停。R2-C 不再训练。硬件错误可修复重跑；不会因为某一折不佳而删掉该折或改参数。

主比较固定使用全局 DSNT（pred），不在新一轮再次从四种解码中选优。每个候选先单独比较，再与原热图模型等权平均；同时报告加入第一轮两个分支后的三者等权平均。总计原提交加 3×3=10 个预定候选；不搜索连续权重，不任意枚举新模型的组合。旧提交保留，新结果写入 outputs/round2。

报告原图 2N 坐标 RMSE、各折 RMSE、尾部误差、逐图变化；对精确重复内容按组作配对 bootstrap，另作去除单个组后的敏感性诊断。bootstrap 只描述固定预测上的抽样波动，不校正选 epoch、模型和解码的选择偏差，不替代独立测试。任何去除样本的数字仅作诊断，不作为正式成绩。

## 论文依据与本项目改法

- [ZIAN 原文](https://arxiv.org/html/2210.02445v2)：方法联合多个尺度 ROI 与全局特征，并通过注意力融合。当前实验仅借鉴多视野的动机，先用更大 ROI 和固定多裁剪平均验证低成本方案，不称为 ZIAN 复现。
- [MSCE 原文](https://arxiv.org/html/2112.04499v1)：中央凹定位转为 X/Y 分类，作者用池化特征、多尺度交叉熵以及 Cellpose 骨干。原文使用 MaxPooling、按轴求和、各尺度权重为 1；任务指标与本赛不同。
- [SimCC 作者摘要](https://arxiv.org/abs/2107.03332)：将人体关键点坐标分成 X/Y 分类并细分像素区间。这里只核对摘要，作为坐标分类的相关工作，不引用未读全文中的消融数字。

R2-B 是本项目的新组合：令 P=softmax(H)，分别边缘化得到 P_x、P_y；按相邻 1、2、4、8 个格点求和得到四个尺度概率，再与相同方式聚合的 Gaussian 目标 Q 做 CE。loss = 四尺度平均的 [CE(Q_x,P_x)+CE(Q_y,P_y)] + 1000×原图坐标归一化 MSE。实现以 logsumexp 聚合对数概率，避免小概率下溢。DSNT 解码不变。它与论文的池化 logits 和独立分类头不同，也没有新增亚像素分类 bins。

## 可以发散、但本轮暂不混在一起的方向

1. **全图与局部特征交互**：如果扩大视野有稳定收益，再做小型门控融合；否则不贸然加入复杂注意力。需与相同参数量的简单拼接比较。
2. **眼底视野标准化**：检测有效视野边界，按视野直径缩放；保留精确逆变换。当前已有两种成像分辨率，单纯固定原图 ROI 可能不对应相同解剖范围。
3. **标签不确定性建模**：当前极少数难图主导平方误差；预测方差可辅助分析，但不能把低置信度当成“不可见”，也不能在没有证据时修改其标签。需重复专家标注才能检验标注歧义。
4. **小规模多种子平均**：若新结构无增益，可测试同结构独立种子以降低方差；在完全相同五折上比较，不能将见过该图的其他折用于 OOF。
5. **解剖几何辅助**：视盘位置、血管弓形状可提供全局约束；目前没有相关真值。应先建立来源明确、可审计的辅助标注，不直接对病变眼套固定视盘—黄斑距离。
6. **不可见分支**：合成遮挡只训练对合成破坏的识别，不能验证真实不可见语义。需要规则允许且来源清楚的真实阴性样本；在此之前不加未经校准的 (0,0) 阈值。
