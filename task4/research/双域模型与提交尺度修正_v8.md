## 新算法：共享细节特征、分开学习两种掩码

新方案由本项目独立实现，使用随机初始化，不引入外部数据或眼底预训练权重。全分辨率特征融合参考 [FRD-Net 原论文摘要](https://pmc.ncbi.nlm.nih.gov/articles/PMC11161363/)中保留细节和多尺度融合的思路；此处的网络、双目标定义、损失、增强和训练代码不是该论文的复现。

1. **输入与细节。** RGB 图像缩放至 512×512，并补充按单张图有效视野标准化的绿色通道、绿色局部对比度，共 5 通道。这些处理只读取对应图像，不跨图拟合统计量。
2. **高分辨率多尺度网络。** 四级残差编码通道为 24、40、64、96，最深只降至 1/8 分辨率；瓶颈使用膨胀率 1、2、3 的分支。四级解码特征各压缩到 8 通道后回到原输入尺寸并融合，保留细小血管信息。全网 561,899 个参数，采用 BatchNorm 和 Dropout2d。
3. **有序双输出。** 细节目标是原标签的最近邻缩放，提交目标是原标签经题目脚本的双线性缩放后判非零。所有训练图逐像素检查前者包含于后者。共享特征输出细节 logit `z` 和宽度修正 `r`，提交 logit 为 `z + softplus(r)`，使提交概率不小于细节概率。
4. **双域监督。** 两个头均用等权 BCE 与 soft Dice；总损失为 `0.4 L_native + 0.6 L_submission + 0.1 L_aux`。辅助头预测半分辨率血管占比，使用面积缩放标签。这里的“双域”指两种标签转换约定，不是训练集与测试集的域自适应。
5. **小样本训练。** 每折仅使用 16 张训练原图，批量 8，160×160 裁块；连续旋转 ±180°、0.85–1.25 倍缩放、翻转和颜色增强。25% 裁块中心来自训练标签的血管位置，其余均匀采样。图像与两种标签使用相同几何映射，标签用最近邻采样。
6. **稳定与评估。** AdamW、150 步预热与余弦学习率，EMA 衰减上限 0.99；每折训练 3,000 步，每 500 步以留出提交尺度 Dice@0.5 选择 EMA 权重，最终用 D4 八变换推理。训练及选择均使用固定五折，测试标签和平台反馈不参与参数梯度。

## 验证范围

已通过 31 项单元测试，包括原有训练和推理接口、真实标签包含关系、几何增强后标签二值性、双输出梯度有限性、不同尺寸的随机掩码与题目原函数编码一致性，以及概率搬运前后已部署基准掩码不变。训练完成后将从最佳检查点重放留出指标，保存 20 张 OOF 概率与逐图 Dice，再与已修正的 v3 基准比较。没有模块级消融，不能把整体差异单独归因于某个新增模块。

额外融合比较预先固定新模型权重为 0、0.25、0.5、0.75、1，最终阈值均为 0.5。先将 v3 原尺寸概率按题目掩码转换的阈值集合映射到提交空间，再平移 logit，使其在 0.5 处逐像素重现已上传 v3 的掩码；这个映射不读取标签。这样两种模型在相同尺寸、相同前景含义下融合。报告全部候选，以及留一折选择权重的敏感性检查。后者仍复用了已有模型和验证图，不能称为新的独立测试。候选需要本地均值增加至少 0.001、至少三折不下降，且留一折选权重的均值优于基准才作为额外候选导出。[固定比较配置](../experiments/dual_domain_fusion_v8.json)

## 完整训练与继续优化结果

五折均完成 3,000 步，累计 15,000 步。最佳 EMA 权重在折 0–4 分别选自第 3,000、2,500、2,500、2,500、1,500 步。所有最佳权重的恒等推理指标精确重放，最终评估使用 D4 推理。

| 方案 | 本地脚本尺度 OOF Dice | 平台 Public Dice |
| --- | ---: | ---: |
| 修正导出后的 v3 | 0.849664 | 0.85697 |
| 新模型单独使用 | 0.836583 | 未测试 |
| 75% v3 + 25% 新模型，阈值 0.50 | 0.850762 | 0.85803 |
| 65% v3 + 35% 新模型，阈值 0.42 | **0.851748** | **0.86017** |

新网络单独使用在五折上均低于修正后的 v3。25% 融合在四折上升、一折下降：折 0–4 的增益分别为 +0.001428、+0.000644、+0.002573、−0.000704、+0.001548。留一折选择权重时五次均选择 25%。因此新网络的有效贡献是组合中的互补信息，不能宣称它独立超过原集成。

用户确认 v8 平台得分 0.85803 并要求继续后，固定比较权重 {0.15, 0.25, 0.35} 与阈值 {0.42, 0.46, 0.50} 的 9 个组合。最佳点的本地 Dice 为 0.851748；留一折选参后的 Dice 为 0.851545。用户对最终 v9 文件确认 Public Dice **0.86017**，比 v8 增加 0.00214。平台成绩没有进入模型梯度或本地参数网格的评分，但它用于确认实际交付版本的优劣。
